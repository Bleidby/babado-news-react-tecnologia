# Babado News - Tecnologia

## Sobre o projeto

O **Babado News** é um projeto acadêmico desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto original consiste em um portal de notícias com foco em informação, entretenimento, esportes, tecnologia, cultura e lifestyle, utilizando tecnologias de desenvolvimento web.

Nesta segunda etapa, o projeto foi desenvolvido individualmente utilizando **React e Vite**. A página de **Tecnologia**, desenvolvida na primeira etapa, foi escolhida para ser integrada ao conteúdo principal do Babado News em uma única Landing Page.

O objetivo é aplicar, na prática, conceitos de **React, JavaScript, CSS, Bootstrap e Git/GitHub**, mantendo a identidade visual do projeto original e adaptando sua estrutura para uma aplicação desenvolvida em React.

---

## Objetivos

- Migrar o conteúdo do projeto original para React.
- Integrar o conteúdo principal do Babado News com a página de Tecnologia.
- Criar uma única Landing Page com navegação por âncoras.
- Utilizar componentes React para organizar a interface.
- Utilizar props e `map()` para criar conteúdos reutilizáveis.
- Preservar a identidade visual do projeto original.
- Criar um layout responsivo para diferentes tamanhos de tela.
- Utilizar Bootstrap e CSS na construção da interface.
- Utilizar Git e GitHub para versionamento do projeto.

## Estrutura do projeto

A Landing Page foi organizada utilizando componentes e seções em React.

Entre os principais componentes estão:

- Navbar
- Footer
- TechnologyCard
- Hero
- Destaques
- Tecnologia
- Newsletter

Os cards da seção de Tecnologia são criados a partir de um array de notícias utilizando `map()`. As informações de cada notícia são enviadas para o componente `TechnologyCard` através de props.

---

## Como executar o projeto

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Instale as dependências:

   `npm install`

4. Inicie o servidor de desenvolvimento:

   `npm run dev`

5. Abra no navegador o endereço informado pelo Vite.
